## 1. Что это за проект

**Ozonologist** — веб-приложение (чат уровня ChatGPT) — AI-ассистент для продавцов Ozon.
Пользователь пишет вопрос → GPT при необходимости вызывает инструменты, которые тянут
данные магазина из Ozon Seller API → GPT анализирует **реальные** данные и отвечает.

Главная идея: GPT **не выдумывает** цифры. Нужны данные — берёт их через инструмент.
Если показатель недоступен (например, реклама без Performance API) — так и говорит.

Репозиторий: https://github.com/westtonery-gif/omemo-ozon (ветка `main`).

## 2. Стек

## 4. Как устроена архитектура

```
Браузер
  ├─ layout.tsx: ConversationsProvider (история чатов, localStorage)
  │              + Sidebar (навигация + история)  ← общий для всех страниц
  ├─ /            page.tsx — чат ("use client"), читает поток ответа
  ├─ /products    Server Component → getProducts()
  ├─ /sales       Server Component → getSalesSummary()
  └─ /finance     Server Component → getSalesSummary()

Чат: fetch POST /api/agent-chat { messages[] }
   ▼
route.ts (ReadableStream):
   цикл tool calling со stream:true →
     content-дельты стримятся клиенту,
     tool_calls собираются и выполняются через runTool()
   ▼
src/agents/tools.ts → src/integrations/ozon/store.ts (isMock решает)
   ├── мок  → mock.ts (MOCK_PRODUCTS / MOCK_SALES)
   └── живой → products.ts (getProductsDetailed) / analytics.ts (getSalesSummaryLive)
```

Промпт агента — `src/agents/ozonologist.ts` (`OZONOLOGIST_PROMPT`).
Общие UI-компоненты — `src/app/_ui/` (conversations, sidebar, page-header, stat-card, format).

## 5. Как запустить

```bash
npm install
# создать .env.local (см. .env.example) и вписать ключи
npm run dev            # → http://localhost:3000
```

Проверка Ozon-подключения отдельно: `npm run test:ozon`.

### Переменные окружения (.env.local, НЕ в git)

| Переменная | Зачем | Обязательна |
|---|---|---|
| `OPENAI_API_KEY` | GPT отвечает | да |
| `OZON_CLIENT_ID` | Seller API | для живого режима |
| `OZON_API_KEY` | Seller API | для живого режима |
| `OZON_MOCK` | `true`/`false` — форс мок/живого режима | нет |
| `OZON_PERFORMANCE_CLIENT_ID/SECRET` | реклама/ДРР (Performance API) | пока не используется |

Без ключей Ozon всё работает на мок-данных. С реальными ключами тот же код идёт на живой Ozon.

### ⚠️ Если OpenAI отвечает `403 unsupported_country_region_territory`

OpenAI блокирует по региону. Если сидишь через **системный прокси** (VPN-клиент вроде
V2Ray на `127.0.0.1:10809`): `Invoke-RestMethod` его видит, а **Node по умолчанию — нет**.
Запускай dev с `NODE_USE_ENV_PROXY=1` (и `HTTPS_PROXY`/`HTTP_PROXY`), тогда серверные
запросы к OpenAI идут через прокси. Альтернатива — задеплоить приложение в поддерживаемом
регионе (тогда прокси не нужен вовсе).

## 6. ⚠️ Подводные камни (обязательно прочитать)

1. **Next.js здесь модифицированный.** В `AGENTS.md` требование: перед написанием кода
   читать гайды в `node_modules/next/dist/docs/`. API могут отличаться от привычных.
2. **`.env.local` не переносится через git** (в `.gitignore`). На новой машине создать заново.
3. **`.claude/` в `.gitignore`** — там `launch.json` с локальным прокси, это машинно-специфично.
4. **Живой путь Ozon НЕ протестирован** (у разработчика мок). Написан по документации:
   - `getProductsDetailed` (`/v3/product/list` + `/v3/product/info/list`);
   - `getSalesSummaryLive` (`/v1/analytics/data`) — сверить названия метрик
     (`revenue`, `ordered_units`, `session_view`) и структуру `result.totals[]`.
5. **Реклама и ДРР** — из отдельного **Performance API** (`api-performance.ozon.ru`, свои
   `client_id`/`client_secret` + OAuth). Пока не подключён → в живом режиме `ad_spend`/`drr`
   = `null` («н/д»), а не 0. Мок эти цифры показывает.
6. **Безопасность:** ранее Ozon-ключ засветился в выводе консоли — рекомендуется перевыпустить.
7. **Два `package-lock.json`** (в `ai-team/` и родителе) — Next ругается про workspace root.

## 8. Как продолжить на другом компьютере

1. `git clone https://github.com/westtonery-gif/omemo-ozon` (или `git pull`).
2. `npm install`.
3. Создать `.env.local` из `.env.example`, вписать ключи (OpenAI обязательно; Ozon — для живого).
4. Открыть Claude Code в папке проекта и дать прочитать этот `PROGRESS.md`.
5. `npm run dev` → http://localhost:3000. При RU-блоке OpenAI — см. раздел 5 про прокси.

> Напоминание: переписка с Claude хранится локально и на другой комп НЕ переезжает —
> контекст передаётся только через этот файл и историю git.
