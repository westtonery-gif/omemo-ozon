## 1. Что это за проект

**Ozonologist** — веб-приложение (чат уровня ChatGPT) — AI-ассистент для продавцов Ozon.
Пользователь пишет вопрос → GPT при необходимости вызывает инструменты, которые тянут
данные магазина из Ozon Seller API → GPT анализирует **реальные** данные и отвечает.

Главная идея: GPT **не выдумывает** цифры. Нужны данные — берёт их через инструмент.

Репозиторий: https://github.com/westtonery-gif/omemo-ozon (ветка `main`).

## 4. Как устроена архитектура

```
Браузер (src/app/page.tsx, "use client")
   │  fetch POST /api/agent-chat { message }
   ▼
API-роут (src/app/api/agent-chat/route.ts)
   │  цикл tool calling (до 5 раундов):
   │  1. openai.chat.completions.create({ messages, tools, tool_choice:"auto" })
   │  2. если GPT попросил инструмент → runTool(name) → результат обратно в messages
   │  3. повторяем, пока GPT не вернёт финальный текст
   ▼
Инструменты (src/agents/tools.ts)
   │  isMock() решает: мок или живой Ozon
   ├── мок  → src/integrations/ozon/mock.ts
   └── живой → src/integrations/ozon/products.ts → client.ts → Ozon Seller API
```

Промпт агента (роль, стиль, формат ответа) — `src/agents/ozonologist.ts`
(экспорт `OZONOLOGIST_PROMPT`, роут его импортирует, дублей нет).

## 5. Как запустить

```bash
npm install
# создать .env.local (см. .env.example) и вписать ключи
npm run dev            # → http://localhost:3000
```

Проверка Ozon-подключения отдельно: `npm run test:ozon`.

### Переменные окружения (.env.local, НЕ в git)

| Переменная | Зачем | Обязательна |
|---|---|---|
| `OPENAI_API_KEY` | GPT отвечает | да |
| `OZON_CLIENT_ID` | доступ к Ozon | для живого режима |
| `OZON_API_KEY` | доступ к Ozon | для живого режима |
| `OZON_MOCK` | `true`/`false` — форс мок/живого режима | нет |

На машине разработчика без Ozon-ключей всё работает на мок-данных.
На машине с реальными ключами тот же код идёт на живой Ozon **без правок кода**.

## 6. ⚠️ Подводные камни (обязательно прочитать)

1. **Next.js здесь модифицированный.** В `AGENTS.md` требование: перед написанием кода
   читать гайды в `node_modules/next/dist/docs/`. API могут отличаться от привычных.
2. **`.env.local` не переносится через git** (в `.gitignore`). На новой машине его надо
   создать заново из `.env.example` и вписать ключи.
3. **Живой путь Ozon (`getProductsDetailed`) НЕ протестирован** — у разработчика мок.
   Написан по документированным эндпоинтам (`/v3/product/list`, `/v3/product/info/list`),
   но проверить можно только с реальными ключами. При первом живом запуске сверить формат
   ответа Ozon и при необходимости поправить маппинг полей.
4. **`get_sales_summary` в живом режиме пока тоже возвращает заглушку** (мок-цифры).
   Реальная аналитика Ozon (`/v1/analytics/data`) ещё не подключена — это TODO.
5. **Безопасность:** ранее Ozon-ключ засветился в выводе консоли. Рекомендуется
   перевыпустить `OZON_API_KEY` в кабинете продавца. В git ключ НЕ попадал (проверено).
6. **Два `package-lock.json`** (в `ai-team/` и в родительской папке) — Next ругается
   предупреждением про workspace root. На работу не влияет, лишний стоит удалить.

## 8. Как продолжить на другом компьютере

1. `git clone https://github.com/westtonery-gif/omemo-ozon` (или `git pull`).
2. `npm install`.
3. Создать `.env.local` из `.env.example`, вписать ключи (OpenAI обязательно;
   Ozon — если нужен живой режим, иначе оставить пустыми → мок).
4. Открыть Claude Code в папке проекта и дать прочитать этот `PROGRESS.md`.
5. `npm run dev` → http://localhost:3000.

> Напоминание: переписка с Claude хранится локально и на другой комп НЕ переезжает —
> контекст передаётся только через этот файл и историю git.
